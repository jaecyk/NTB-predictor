# Live Fetch Quickstart

This flow replaces manual typing and lets you fetch snapshot rows from a remote maintained source.

## Files added
- `live_fetch_and_ingest.py`
- `live_source_template.json`

## What the script can do
- fetch a remote JSON feed
- fetch a remote CSV feed
- normalize snapshot rows into the required schema
- write a local normalized CSV file
- post the rows directly into the backend API

## Supported remote JSON shapes

### Shape 1: list of rows
```json
[
  {
    "auction_date": "2026-04-05",
    "tenor_days": 91,
    "lag1_stop": 16.10,
    "lag2_stop": 15.95,
    "lag3_stop": 15.80,
    "offer_amt": 80.0,
    "prev_offer": 80.0,
    "prev_bid_cover": 2.20,
    "sec_rate": 16.0943,
    "sec_rate_5d_ago": 16.0500,
    "system_liquidity": 2780.0,
    "mpr": 26.5,
    "inflation": 15.06,
    "source": "remote_feed"
  }
]
```

### Shape 2: object with `snapshots`
```json
{
  "snapshots": [ ... ]
}
```

### Shape 3: object with `shared` + `tenors`
See `live_source_template.json`.

## Fastest test
If you host `live_source_template.json` somewhere accessible by URL, run:

```bash
python live_fetch_and_ingest.py --source-url https://your-source/live_source.json --print-only
```

## Write normalized CSV only
```bash
python live_fetch_and_ingest.py --source-url https://your-source/live_source.json
```

This writes:
- `latest_snapshots.csv`

## Write CSV and post directly into the API
```bash
python live_fetch_and_ingest.py --source-url https://your-source/live_source.json --post-api
```

## CSV remote source example
If your remote source is already a CSV with the required columns:

```bash
python live_fetch_and_ingest.py --source-url https://your-source/daily_snapshot.csv --source-format csv --post-api
```

## Full practical flow
1. keep backend running
2. run `live_fetch_and_ingest.py`
3. it fetches the remote feed
4. it normalizes the rows
5. it writes `latest_snapshots.csv`
6. it optionally posts into `/snapshots`
7. frontend then reads `/snapshots/latest` and `/predict/latest`

## Suggested use cases
- remote Google Sheet published as CSV
- internal JSON feed generated by another script
- hosted static JSON file updated daily
- lightweight internal service exposing the snapshot payload

## Important note
The script is source-agnostic on purpose.
You can point it to your real approved market data feed without changing the frontend.
